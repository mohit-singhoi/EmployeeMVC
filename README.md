# EmployeeMVC

My **first Spring Boot project** — a simple Employee Management application built to learn the basics of **Spring Boot, Spring MVC, Thymeleaf, and H2 Database**.

## 🚀 Features

* ➕ Add employee details
* 💾 Save employee data in **H2 Database**
* 📋 Display all employees
* 🌐 Simple web interface

## 🛠️ Technologies

**Java | Spring Boot | Spring MVC | Thymeleaf | Spring Data JPA | H2 Database | Maven | HTML | CSS**

## ▶️ Run the Project

```bash
mvnw.cmd spring-boot:run
```

Open in your browser:

```text
http://localhost:8080
```

## 👨‍💻 About

This is my **first Spring Boot project**, created to understand the fundamentals of building a web application and connecting it with an H2 database.
